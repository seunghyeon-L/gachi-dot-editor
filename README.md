# 가치고치 도트 편집기

**사람과 AI 가 같은 도트 그림을 같이 고치는** Aseprite 풍 도트 편집기입니다. 게임 **가치고치**(제주 친환경 게이미피케이션) 의 도트 그림(캐릭터·타일·아이콘)을 그리려고 만들었습니다.

- 사람은 브라우저 화면에서 마우스·단축키로, AI 는 터미널 명령(`dot.mjs`)이나 파일로 **같은 문서**를 고칩니다. 되돌리기 기록도 같이 씁니다.
- 그림 한 장이 **글자 칸**(한 글자 = 한 픽셀 = 팔레트 색 하나)으로 저장돼서, 32×32 로 정하면 늘 정확히 32×32 입니다. 이미지 생성 AI 처럼 칸이 깨지거나 흐린 가장자리·엉뚱한 색이 생기지 않습니다.
- 의존성 없음 (Node 18 이상만 있으면 됨). 저장은 자동.

> **AI 에게 맡기는 분**: AI 도구(Claude Code, Codex, Cursor 등)로 이 폴더를 열면 [AGENTS.md](AGENTS.md)(Claude Code 는 [CLAUDE.md](CLAUDE.md))를 읽고 이 편집기로 그립니다. "palette-characters 로 32×32 ○○ 그려 줘" 처럼 시키면 됩니다.

## 시작

```bash
git clone <이 저장소 주소>
cd gachi-dot-editor
node server.mjs          # → http://localhost:5191 을 브라우저로 열기
node dot.mjs help        # AI·터미널용 명령 목록 (다른 창에서)
```

포트 바꾸기: `PORT=5300 node server.mjs` (명령도 `PORT=5300 node dot.mjs …`).

## 사람: 화면

위 메뉴·도구 옵션 / 왼쪽 도구·팔레트 / 가운데 캔버스 / 오른쪽 미리보기·작업 기록 / 아래 타임라인. 화면의 `?` 버튼에 단축키 전체가 있습니다.

| 단축키 | 하는 일 |
| --- | --- |
| B E G I | 연필 · 지우개 · 페인트 통 · 스포이트 (Alt+클릭 = 스포이트) |
| L U O | 직선 · 사각형 · 원 (Shift: 45도 / 정사각형 / 정원) |
| M V H | 사각 선택 · 이동 · 손 (Space+끌기 = 화면 이동) |
| 왼쪽/오른쪽 클릭 | 앞색/뒷색. 연필 Shift+클릭 = 직선 |
| X, [ ] | 앞뒷색 바꾸기, 붓 크기 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 (AI 작업도 같이) |
| Ctrl+C X V, Delete | 복사·잘라내기·붙여넣기, 선택 영역 지우기 |
| Shift+H / Shift+V | 좌우/상하 뒤집기 |
| 휠, + − 0 | 확대·축소, 화면 맞춤 |

- 연필 옵션: **픽셀 퍼펙트**(ㄱ자 꺾임 없애기), **좌우 대칭**, 붓 크기.
- 팔레트: 클릭 앞색, 오른쪽 클릭 뒷색, 더블클릭 색 바꾸기(쓴 곳 전부), `+` 추가, `정리` 안 쓰는 색 지우기.
- AI 가 바꾸면 바뀐 픽셀이 노랗게 깜빡이고 아래에 알림이 뜹니다. 작업 기록에서 누가(나 / AI) 무엇을 했는지 보고 그 시점으로 돌아갈 수 있습니다.
- 애니메이션(프레임·레이어·태그·어니언 스킨)도 됩니다 — 정지 그림은 프레임 0 하나만 쓰면 됩니다.

## 파일 형식 (`projects/<이름>.dot.json`)

```json
{
  "format": "gachi-dot/1",
  "name": "example-tangerine",
  "width": 16, "height": 16,
  "pivot": [8, 15],
  "palette": [
    ["a", "#000000", "외곽선"],
    ["t", "#ff8a3d", "몸"]
  ],
  "layers": [ {"name": "그림", "visible": true, "opacity": 255, "locked": false} ],
  "frames": [100],
  "tags": [],
  "cels": [
    { "layer": "그림", "frame": 0, "rows": [
        "................",
        "......aaaa......",
        ".....atttta....."
    ] }
  ]
}
```

- 줄마다 그림 한 줄이라 **파일을 읽기만 해도 그림이 보입니다.** `.` = 투명, 글자 = 팔레트 색.
- 서버가 켜져 있을 때 파일을 직접 고치면 화면에 바로 반영됩니다. 잘못 고치면 화면에 오류가 뜨고 문서는 그대로.
- 팔레트는 Aseprite 인덱스 모드처럼 색마다 글자 하나 (최대 81색). 팔레트 색을 바꾸면 그 색을 쓴 곳이 모두 바뀝니다.

## 내보내기

`node dot.mjs export [--scale n] --p <이름>` → `export/<이름>/`

- `<이름>_static.png` — 그림 한 장 (프레임 0)
- `<이름>.png` + `<이름>.json` — 시트 + Aseprite JSON(hash) 과 같은 모양 (애니메이션일 때)
- `--scale 16` → 32×32 그림이 512×512 로 (칸마다 16×16 픽셀, 흐림 없음). 게임 앱의 그림 파일이 이 크기입니다.

## Aseprite 와 다른 점

- 색 모드는 인덱스 하나 (RGB 모드 없음, 팔레트 최대 81색)
- 셀은 캔버스 크기 고정, 레이어 그룹·혼합 모드 없음
- 잉크(셰이딩)·스프레이·그라데이션·임의 각도 회전·크기 바꾸기 없음 (90도 회전은 명령으로)
